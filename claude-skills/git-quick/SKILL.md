# Quick Git

Fast git for $ARGUMENTS.

## Commands
- `/git-quick s` or `status` - git status
- `/git-quick d` or `diff` - git diff
- `/git-quick l` or `log` - last 10 commits oneline
- `/git-quick p` or `push` - push to origin
- `/git-quick sync` - pull --rebase && push
